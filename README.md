# RoadGuard AI

A mobile-first, real-time **road-geometry advisory** app. It routes a trip, extracts
curve geometry from the mapped polyline, scores each section's **geometry challenge**, and
warns before tight curves at your assumed speed band.

> **This is not an accident predictor and not a safety score.** The output is a geometry
> challenge indicator — *not an accident probability*. It never tells you a route is
> "safe"; it can only say which mapped route has the lowest geometry challenge, and only
> when evidence is comparable. See [docs/LIMITATIONS.md](docs/LIMITATIONS.md).

## What is real and what is synthetic

- Runtime uses **OpenStreetMap geometry** (OSRM routing, Nominatim geocoding) and community
  hazard reports. These are real external data sources.
- The ML model (GACE) is trained **only on synthetic scenarios** from a documented physics
  label. No real crash data, GPS traces, or Indian road observations were used, and none
  are claimed. See [docs/DATA_AND_PROVENANCE.md](docs/DATA_AND_PROVENANCE.md).

## Setup

```bash
git clone <REPOSITORY URL — REQUIRES STUDENT INPUT>
cd RoadGuard
python -m venv .venv
# Windows: .venv\Scripts\activate    Unix: source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env        # then edit values
```

`.env.example` documents every setting read by `app/config.py`. Fill the provider
User-Agent contact (`REQUIRES STUDENT INPUT`) before any non-local use. Set
`ROADGUARD_COOKIE_SECURE=true` behind HTTPS in production.

## Run

```bash
uvicorn app.main:app --reload
```

- Rider app: http://127.0.0.1:8000/
- Admin console: http://127.0.0.1:8000/admin
- API + docs: http://127.0.0.1:8000/docs (schema is generated by FastAPI)
- Health / readiness: `/health`, `/ready`

First start runs DB migrations (WAL) and loads `ml/artifacts/model.joblib` once. If the
artifact is missing and `ROADGUARD_REQUIRE_MODEL=false`, the app still serves routes using
the physics baseline and reports model status as `unavailable` (no silent failure).

## Create an administrator

```bash
python scripts/create_admin.py --email you@example.com
```

Password is read with `getpass` — never passed on the command line or logged.

## Train / re-generate the model (offline; never imported by the server)

```bash
python -m ml.train --seed 42 --per-type 140
```

Reproduces `ml/artifacts/` (`model.joblib`, `eval_results.json`, `MODEL_CARD.md`, dataset
hash `5e92447a…d5db9d`). See [ml/artifacts/REPRODUCE.md](../ml/artifacts/REPRODUCE.md).

## Test

```bash
python -m pytest -q                 # 105 backend tests
node --test "tests/js/**/*.test.js" # 23 frontend unit tests (no build step, Node ≥ 22)
npx playwright test                 # 12 rider+admin E2E cases (mock-labelled providers; boots the real ASGI app)
python -m ruff check app ml scripts tests        # clean
python -m mypy app ml scripts --ignore-missing-imports  # clean (29 files)
python -m pip_audit -r requirements.txt          # no known vulnerabilities
python scripts/bench_server.py                   # analyze latency/throughput + scoring before/after (offline)
python scripts/bench_provider_live.py --confirm  # OPT-IN live Nominatim/OSRM round-trip (needs network)
```

Backend: geometry, baseline, aggregation, advisory, security, model, API, DB backup/restore,
compliance, staged-alert wiring. Frontend unit tests (`tests/js`) cover the pure alert
planner + settings persistence. **Playwright E2E** (`tests/e2e`, `npx playwright test`) drives
the rider nav state machine, cue playback, trip summary and the insufficient-evidence /
provider-failure paths, plus the admin console's login/role gating, tab switching, moderation
and diagnostics — all against the real app with **`mock`-labelled providers** (12 cases); first
run needs `npm ci && npx playwright install chromium`. **`ruff`, `mypy`, and `pip-audit` are run
clean and are CI-blocking.** Performance is measured (server before/after, live provider, client
render/soak — see [docs/PERFORMANCE_REPORT.md](docs/PERFORMANCE_REPORT.md)). Remaining: a live
`docker build` verification (deferred by student request) — see [docs/LOOP_STATE.md](docs/LOOP_STATE.md).

## Demo script (happy path)

1. Open `/` → allow location → chip shows a fresh fix.
2. Search a destination (Nominatim, India-restricted) → pick → **Route**.
3. OSRM returns up to 3 alternatives; each shows a geometry-challenge score + coverage.
   Comparable-but-close routes return **no recommendation** (honesty over false ranking).
4. **Start navigation** → advisory card appears with lead time before a tight curve,
   labelled "Advisory only; based on mapped road shape".
5. **Report hazard** (requires login) → appears as *Community report — unverified*.
6. `/admin` (admin login) → verify/reject the report; audit records `hazard_verified` /
   `hazard_rejected`.
